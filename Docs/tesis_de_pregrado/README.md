# 🎓 Tesis de Pregrado

Este directorio centraliza las memorias académicas, código y experimentos desarrollados por estudiantes de pregrado en el marco de **SavIA Admin** y la infraestructura de **SavIA Lab**.

---

## 🎯 Alcance

Garantizar la trazabilidad, reproducibilidad y continuidad técnica de las contribuciones realizadas al proyecto a través de trabajos de grado.

## 📂 Estructura Sugerida

Cada trabajo debe alojarse en una carpeta propia siguiendo la convención `[Año]_[Nombre]_[Tema]`:

```text
tesis_de_pregrado/
└── 2026_JuanPerez_IntegracionSlurm/
    ├── docs/         # Memoria escrita (PDF/LaTeX) y diagramas
    ├── src/          # Código fuente, scripts o APIs desarrolladas
    ├── experiments/  # Benchmarks, scripts de prueba y logs
    └── README.md     # Resumen ejecutivo del proyecto y guía de ejecución
